# Migration

The archived Claude skill promised a twelve-tab MSA workbook. Direct source review found empty variance/results worksheets, an undefined Range pseudo-formula, and an example declaring ten parts while supplying two. A rename would preserve these defects.

This derivative replaces the generator with a dependency-free balanced crossed ANOVA analyzer and validated JSON/HTML outputs. Removed Claude-specific installation, spreadsheet recalc/LibreOffice helpers, unsupported attribute/bias/linearity claims and unrelated metrics. The original archive and extracted source are preserved in the control project's ignored source snapshots; immutable source revision, extracted-tree digest and MIT notice are recorded here.

Scope is intentionally explicit: retained interaction, variable measurements only, no automatic suitability decision. Python scripts and mathematical golden tests provide a repeatable public workflow. The skill entrypoint uses Matt Pocock's contextual pointers: read the input reference when mapping data and the methodology reference when explaining the model. Completion requires validated reports, not a formatted scaffold.
