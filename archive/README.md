# Historical archive

This directory preserves superseded project material. It is not the active workflow and is not startup context.

- history/: old candidate ledger, discovery/review records, drafts, reports, documentation and retired schedule configuration.
- local/: ignored upstream checkouts, raw caches, private execution logs and publication checkouts.
- history/manifest.json: original-to-archive path mapping.

No upstream repository or public skill was deleted. Credentials and Telegram delivery receipts remain at their existing ignored active paths to preserve configuration and duplicate-send protection.

Historical records retain their original source paths and evidence hashes. Restore history/ and local/ to their recorded original workspace layout if replay is needed. Keep private local material out of Git.
