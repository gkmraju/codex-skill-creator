# Compatibility

Python 3.10+ standard library; no third-party dependencies, network, shell commands, credentials or office software in the analyzer. Portable pathlib paths and UTF-8 JSON/HTML. Repository-level installation copies one skill to .agents/skills/msa-gage-rr-builder. Source notices remain verbatim in licenses/.

The script accepts a balanced crossed dataset and a fresh output directory. Errors leave source data unchanged. JSON rejects duplicate keys, nonfinite readings and incomplete designs. HTML escapes supplied metadata and contains no external assets or scripts. Interaction pooling and automatic acceptance are deliberately outside scope.

Native Codex discovery, independent instruction-following evaluation and local Python tests are recorded in the control repository; exact verified results are summarized in docs/evaluation.md. The compatibility plugin manifest is structurally checked; plugin installation is not tested.
